# NOCTURNE — Neon Night

A rain-wet service alley with cyan and pink neon, warm shop windows, scanned street props, and PBR masonry.

The bundled source models and texture maps are from [Poly Haven](https://polyhaven.com), distributed under [CC0 1.0](https://polyhaven.com/license). No account or network connection is needed to run the scene. Source files are unmodified; scene assembly selects variants and places/scales instances.

`assets.json` pins every download URL and SHA-256 digest. Models use the 1K glTF packages; the three architectural texture sets use 2K diffuse, OpenGL normal, and packed ambient-occlusion/roughness/metallic maps.

The alley architecture, layout, wet-surface material adjustments and sign designs are original project content, generated by `engine/tools/build_neon_scene.py`. Sign textures use DejaVu Sans typography; the font itself is not bundled. CC0 assets retain their original license independently of the project license.

To restore missing source files, run `python3 engine/tools/fetch_neon_assets.py`. To regenerate the scene after layout edits, run `python3 engine/tools/build_neon_scene.py` (requires ImageMagick and DejaVu Sans). Rebuild the app afterward to copy the scene into its runtime folder. Neither step is needed for normal use.
